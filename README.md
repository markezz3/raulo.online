# Raulo Online

Raulo Online es un sitio web personal diseñado para centralizar herramientas útiles y facilitar pruebas de optimización en entornos Windows.

## Descripción

Este proyecto combina una interfaz web simple con utilidades de diagnóstico y enlaces de descarga. Está pensado como una base de desarrollo para futuras integraciones, como sistemas de autenticación, paneles administrativos y automatizaciones.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
- IIS
- Visual Studio Code
- ChatGPT
- VPS
- Dominios (GoDaddy)


## Objetivo

Desarrollar una página web personal con integración futura de:

- Interfaz web moderna y responsiva
- Login con credenciales de acceso
- Automatizaciones y scripts de apoyo
- Panel administrativo para gestión
- Integración con bases de datos
- Descargas seguras para herramientas y utilidades

## Advertencia importante

Las herramientas y scripts incluidos en este proyecto son de terceros o de uso experimental. Se proporcionan únicamente para pruebas, investigación y aprendizaje.

> El uso de estas utilidades es responsabilidad del usuario. Antes de ejecutar cualquier herramienta o descargar archivos, revisa su origen, entiende sus efectos y procede con cuidado.

## Deploy

El proyecto se sincroniza mediante GitHub y Git hacia el VPS.
