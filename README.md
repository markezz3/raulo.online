## Tecnologías utilizadas

	- HTML
	- CSS
	- JavaScript
	- Git
	- GitHub
	- IIS
	- Visual Code

Desarrollar una página web personal con integración futura de:

	- Python

	- Automatizaciones
	- Panel administrativo
	- Base de datos
	- Descargas
